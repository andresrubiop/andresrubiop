I work on **high-performance computing, GPU and memory systems, and practical AI**. I hold a PhD in Computer Science from Université de Bordeaux, with research experience at **Inria** and **RIKEN R-CCS**. I currently teach and develop AI projects at Universidad Tecnológica Indoamérica in Ecuador.

My focus is making systems measurable: how they use memory, how they behave under concurrency, how well models generalize, and what an agent is actually allowed to do.

### Selected engineering projects

| Project | What to look at |
| --- | --- |
| [GPU Inference Benchmarks](https://github.com/andresrubiop/gpu-inference-benchmarks) | LLM inference under concurrency; latency, throughput, GPU memory and power. Portable benchmark tooling and documented A100 measurements. |
| [LEO Desktop](https://github.com/andresrubiop/leo-desktop) | A local desktop agent for GNOME/Wayland: Ollama, typed tools, one-use approvals, reversible file actions and an illustrated companion. |
| [Ecuadorian Sign Recognition](https://github.com/andresrubiop/ecsl-sign-recognition) | CUDA training, temporal models and signer-disjoint evaluation for a constrained Ecuadorian Sign Language vocabulary. Source code and numerical evaluation, with model/data distribution kept explicit. |
| [Academic Timetabling](https://github.com/andresrubiop/academic-timetabling) | Constraint-based academic scheduling with CP-SAT/LNS, PostgreSQL, FastAPI and a Next.js interface. Research software with documented limits. |
